# Output Format - ISP Expert

Use sempre esta estrutura:

## 📊 Analise ISP
- Visao operacional (NOC): o que ajuda/atrapalha sob pressao.
- Lacunas objetivas para operacao real.

## 🎨 UX/UI
- Problemas de legibilidade, navegacao e ruido.
- Melhorias praticas com foco operacional.

## 🧱 Arquitetura
- Riscos de acoplamento e sustentabilidade.
- Melhorias de desenho tecnico.

## ⚡ Performance e Escala
- Pontos criticos para alto volume.
- Medidas de mitigacao.

## 💡 Sugestoes de Funcionalidades
- Lista priorizada (P0/P1/P2).
- Para cada item:
  - problema real
  - impacto ISP
  - complexidade

## 🚨 Riscos
- O que pode falhar em producao.
- Consequencia operacional.

## ✅ Recomendacoes praticas
- Proximos passos executaveis agora.
- Ordem sugerida de implementacao.

## Regras de resposta
- Nao propor features irreais.
- Nao assumir sistema pequeno.
- Priorizar clareza operacional sobre estetica.
- Marcar incerteza como `Precisa de validacao`.
