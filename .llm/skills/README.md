# Skills locais - como criar e manter

## Objetivo
Skills sao playbooks curtos e repetiveis para tarefas recorrentes de engenharia neste repositorio.

## Estrutura padrao de skill
- `README.md`: quando usar, entradas, passos e saida esperada.
- `checklist.md`: verificacoes objetivas de execucao.
- `output-format.md`: formato de resposta para manter consistencia entre agentes.

## Regras
- Cada skill deve apontar caminhos reais de arquivo/comando.
- Evitar teoria ampla; manter foco operacional.
- Incluir limites de escopo e riscos comuns.
- Atualizar a skill quando o fluxo real mudar.
