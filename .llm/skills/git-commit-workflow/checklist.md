# Checklist - Git Commit Workflow

- [ ] O diff do commit atende um unico objetivo tecnico.
- [ ] Nao inclui alteracoes acidentais de arquivos nao relacionados.
- [ ] Documentacao relevante foi atualizada no mesmo contexto.
- [ ] Testes/lint/security foram executados ou justificados.
- [ ] Mensagem do commit descreve impacto real.
- [ ] Historico `.llm/history/changes.md` atualizado (quando aplicavel).
