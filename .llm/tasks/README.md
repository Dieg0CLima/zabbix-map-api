# Execucao de tarefas por agentes

## Fluxo recomendado
1. Ler `.llm/README.md`, `.llm/idea.md` e `context/*.md`.
2. Abrir tarefa usando `task-template.md`.
3. Implementar a menor mudanca correta possivel.
4. Validar com testes/comandos relevantes.
5. Atualizar docs afetadas e registrar historico.

## Regras de operacao
- Nao editar sem mapear arquivos de impacto.
- Nao assumir requisitos nao documentados; marcar incertezas.
- Priorizar seguranca, escopo organizacional e compatibilidade de contrato.
- Se houver mudanca arquitetural, registrar ADR.
